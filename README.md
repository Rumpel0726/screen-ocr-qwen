# Screen OCR · Qwen3-VL

Распознавание текста с любой области экрана по горячей клавише — с помощью vision-модели **Qwen3-VL-8B** через OpenAI-совместимый API [RouterAI](https://routerai.ru).
Нажимаешь хоткей, выделяешь кусок экрана, и текст уже в буфере обмена. По этому же фрагменту можно сразу задать модели вопрос: перевести, объяснить ошибку, посчитать.

*Hotkey-driven screen OCR for Windows powered by the Qwen3-VL vision model: select a region → text goes to the clipboard → ask follow-up questions about it.*

## Возможности

- **Глобальный хоткей** `Ctrl+Shift+F9` работает из любого приложения, скрипт висит в фоне.
- **Выделение области мышью**: экран затемняется, курсор становится перекрестием, `Esc` или правая кнопка отменяют выделение.
- **Несколько мониторов и HiDPI**: координаты считаются по всему виртуальному рабочему столу, DPI awareness включается до создания окон, поэтому на масштабе 125–150 % выделение не съезжает.
- **Результат сразу в буфере обмена** и в компактном окне без лишнего интерфейса.
- **Диалог по фрагменту**: картинка и распознанный текст остаются в контексте, вопросы можно задавать подряд. Модель отвечает на языке вопроса.
- **Копирование на любой раскладке**: `Ctrl+C`, `Ctrl+A` и `Ctrl+V` привязаны к виртуальным кодам клавиш, а не к символам, поэтому работают и на русской раскладке (стандартные биндинги Tk там ломаются). Есть контекстное меню и кнопка «Копировать ответ».
- **Экономия токенов**: широкие области ужимаются до 1600 px по ширине, история диалога ограничена.
- **Понятные ошибки**: для 401, 402, 404, 429, таймаутов и проблем с сетью показывается подсказка, что делать.
- **Минимум зависимостей**: пять пакетов из PyPI, загрузчик `.env` встроен.

## Как это работает

```
хоткей (pynput) ──► оверлей выделения (tkinter) ──► скриншот (mss)
      ──► даунскейл + PNG/base64 (Pillow) ──► Qwen3-VL через RouterAI (requests)
      ──► буфер обмена (pyperclip) + окно результата с чатом
```

Сетевые запросы выполняются в фоновых потоках, а результаты передаются в GUI-поток через очередь, поэтому интерфейс не зависает, пока модель думает.

## Установка

Нужны Windows 10/11 и Python 3.11+ с python.org (tkinter входит в стандартную поставку).

```powershell
git clone https://github.com/Rumpel0726/screen-ocr-qwen.git
cd screen-ocr-qwen
py -m pip install -r requirements.txt
```

Получите API-ключ в личном кабинете [routerai.ru](https://routerai.ru) и создайте файл `.env` по шаблону:

```powershell
copy .env.example .env
# затем впишите ключ: ROUTERAI_API_KEY=sk-...
```

> `.env` внесён в `.gitignore`. Если переменная окружения `ROUTERAI_API_KEY` задана, она имеет приоритет над файлом.

## Запуск

```powershell
py ocr_qwen.py     # с консолью: видны логи и ошибки
pyw ocr_qwen.py    # без консоли, в фоне
```

| Действие | Клавиши |
|---|---|
| Начать захват | `Ctrl+Shift+F9` |
| Отменить выделение | `Esc` / правая кнопка мыши |
| Отправить вопрос | `Enter` |
| Очистить поле / закрыть окно | `Esc` |
| Копировать выделенное / всё | `Ctrl+C` / `Ctrl+A` → `Ctrl+C` |

### Автозапуск с Windows

1. `Win+R` → `shell:startup` → `Enter`.
2. Создайте там ярлык с объектом:
   ```
   "<путь>\pythonw.exe" "<путь к проекту>\ocr_qwen.py"
   ```
   Путь к `pythonw.exe` покажет команда `where pythonw`.

Ярлык надёжнее `.cmd`, если в пути есть кириллица: `.cmd` читается в кодировке OEM, и путь может побиться. Скрипт находит `.env` относительно своего файла, а не текущей папки, поэтому из автозагрузки ключ тоже подхватывается.

Иконки в трее нет. Завершить скрипт можно через Диспетчер задач (процесс `pythonw.exe`).

## Настройка

Все параметры собраны в блоке `КОНФИГ` в начале [`ocr_qwen.py`](ocr_qwen.py):

| Параметр | По умолчанию | Назначение |
|---|---|---|
| `HOTKEY` | `<ctrl>+<shift>+<f9>` | Глобальное сочетание клавиш (формат pynput) |
| `MODEL` | `qwen/qwen3-vl-8b-instruct` | Любая vision-модель RouterAI (`text+image->text`) |
| `MAX_IMAGE_WIDTH` | `1600` | Ширина, до которой ужимается скриншот |
| `REQUEST_TIMEOUT` | `(10, 120)` | Таймауты на соединение и ответ, с |
| `CHAT_HISTORY_LIMIT` | `12` | Сколько сообщений диалога хранить |
| `PROMPT`, `CHAT_SYSTEM` | — | Промпты для распознавания и режима вопросов |

Эндпоинт OpenAI-совместимый, поэтому, поменяв `API_URL` и `MODEL`, скрипт можно перевести на другого провайдера.
